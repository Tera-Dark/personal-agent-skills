# Creative System Overview

## Philosophy

Personal Agent Skills is designed around a human creative workflow rather than direct prompt generation.

A prompt is not the design itself.

A prompt is a language used to communicate a design decision to a model.

---

## Traditional Creative Flow

```
Idea
 ↓
Concept
 ↓
Design
 ↓
Production
```

## AI Creative Flow

```
User Intent
 ↓
Creative Understanding
 ↓
Design Decision
 ↓
Prompt Engineering
 ↓
Generation
```

---

## Core Layers

### Identity Layer

Defines the creator's long-term preferences, goals and constraints.

Question answered:

"Who is this work created for?"

---

### Creative Direction Layer

Transforms a request into an artistic direction.

Responsibilities:

- define emotional tone
- establish visual identity
- remove meaningless AI complexity
- guide design decisions

Question answered:

"Why should this artwork exist?"

---

### Specialist Layer

Handles execution details.

Examples:

- NAI5 weighted tags
- Anima natural language prompts
- ComfyUI workflows

Question answered:

"How should this model understand the idea?"

---

## Design Principle

High quality creative output comes from:

```
Strong idea
+
Clear visual identity
+
Appropriate expression method
```

Not from:

```
More keywords
+
More random details
```

---

## Avoid AI-like Creation

Common AI behavior:

- adding random accessories
- increasing complexity without purpose
- combining unrelated aesthetics
- optimizing appearance without personality

The system prioritizes:

- character identity
- emotional connection
- visual memory
- meaningful details

---

## Final Principle

The purpose of this system is not to generate more images.

The purpose is to help create better designs.
