# Tera Visual Aesthetic Profile

This file stores stable personal visual preferences shared by creative skills.

## Primary direction

- Female-oriented character design
- Commercial gacha illustration quality
- High-fashion costume thinking
- Strong silhouette recognition
- Character personality through pose and styling

## Preferred design language

Emphasize:

- layered clothing construction
- asymmetric details
- refined accessories
- fabric differences
- elegant color relationships
- memorable motifs
- emotional expression

## Avoid by default

Avoid unless specifically requested:

- excessive cyberpunk
- heavy mechanical elements
- generic armor fantasy
- random technology decorations
- unnecessary watches or modern gadgets

## Illustration preference

Prefer:

- atmospheric storytelling
- intentional empty space
- cinematic composition
- visual poetry
- fashion illustration influence

## Character prompt principles

A good design should communicate:

1. Who is this character?
2. What is their personality?
3. What makes their costume unique?
4. What visual memory remains after viewing?
