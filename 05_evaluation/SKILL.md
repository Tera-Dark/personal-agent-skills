# Evaluation Loop

## Purpose

Create a feedback loop between generation and refinement.

## Responsibilities

- Analyze output quality
- Identify failure causes
- Suggest targeted revisions
- Compare against creative intent

## Evaluation Order

1. Identity consistency
2. Visual appeal
3. Composition
4. Expression and emotion
5. Costume/design coherence
6. Technical quality

## Avoid

Do not only judge technical quality.
A correct image can still fail if it lacks character or emotion.
