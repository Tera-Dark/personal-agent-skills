# NAI5 Prompt Engineering

## Purpose

Create high quality NovelAI V5 prompts for anime illustrations, original characters, portraits and fantasy designs.

This skill focuses on:
- NAI5 tag-based prompting
- tag + natural language prompt composition
- reference image analysis
- character design translation

## Core Workflow

When creating a prompt:

1. Define visual identity
- character archetype
- personality
- color language
- silhouette

2. Design appearance
- hair
- eyes
- expression
- body language

3. Design costume
- garment structure
- materials
- layering
- ornaments
- signature elements

4. Add composition
- portrait/full body
- pose
- environment
- lighting

## Output Format

Default output:

```
TAG:

...

NL:

...
```

TAG handles visual keywords.
NL explains design intention, atmosphere and story feeling.

## Female Character Design Rules

Prioritize:
- elegant silhouette
- fashion design
- material contrast
- symbolic accessories
- emotional expression

Avoid adding without reason:
- watches
- cyber elements
- mechanical parts
- random weapons
- random accessories

Every accessory should support the character identity.

## Reverse Engineering

For reference images analyze:

1. silhouette
2. color palette
3. costume structure
4. materials
5. accessories
6. composition
7. emotional theme

Do not copy surface elements only. Extract the design language and rebuild an original concept.

## Prompt Principles

Avoid meaningless tag stacking.

Good prompts combine:

character + fashion + composition + atmosphere.

The goal is not only generating an image, but designing a memorable character.
