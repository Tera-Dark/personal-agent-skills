# NAI5 Community Prompt Format

Standard format:

```
[artist stack]

[global style]

[scene]

char1:
...

char2:
...

Negative:
...
```

## Character Blocks

Keep character identity isolated.

Example:

```
char1:
girl, character name, hair, eyes, outfit, action
```

## Weight Syntax

Common community syntax:

```
1.5::tag::
-2::tag::
```

Positive weights strengthen concepts.
Negative weights suppress concepts.

## Philosophy

Prefer dense visual tokens over long descriptive paragraphs.
