# Creative Moves — 九个创作动作的具体手法

> 本文件是 `aesthetic-director-core` 的操作手册。每个动作给出：它解决什么、AI 默认会怎么做、设计师会怎么做、可直接套用的手法、检验标准。
> 目的不是让 AI 背规则，而是给它**可执行的替代动作**。只有禁令没有动作，模型会退回最安全的平庸。

---

## M1 · 找到痴迷点 Find the Obsession

**解决什么**：设计没有中心，所有元素平权。

**AI 默认**：从职业/种族/风格标签出发——"精灵弓箭手"、"哥特女仆"、"赛博巫女"。标签是集合名词，它召唤的是该集合的平均值。

**设计师**：从一个**具体的视觉念头**出发，职业是后加的。念头必须包含一个动词或一个物理关系。

**手法**：
1. 先问：如果这张图只允许保留一个东西让人记住，是什么？
2. 把答案写成 `[主体] + [动词/关系] + [对象]`。
   - ✗ `a moon priestess`
   - ✓ `a priestess whose veil is actually the moon's reflection she carries in a bowl`
   - ✗ `a swordswoman`
   - ✓ `a swordswoman who wears her sheath as a spine brace because the sword is too heavy for her`
3. 职业、种族、时代——全部从这个念头往回推，而不是反过来。

**检验**：把念头念给一个没看图的人听，他能不能在脑子里出现一个**形状**？出现的是形状就对了，出现的是"感觉"就还没到。

## M2 · 埋一个矛盾 Plant a Contradiction

**解决什么**：角色单维度，只是某种气质的纯度展示。

**AI 默认**：气质叠加同向词——温柔 + 治愈 + 柔和 + 花；或冷酷 + 黑 + 刀 + 血。

**设计师**：让两个不该在一起的东西共存，且**都可见**。矛盾是记忆点的引擎。

**手法**（选一个轴，不要同时用多个）：
| 轴 | 例 |
|---|---|
| 身份 vs 行为 | 宫廷档案员，在培育毒花 |
| 材质 vs 场合 | 礼服的下摆是泥的，因为她走了很远的路 |
| 精致 vs 破损 | 绣工极细的手套，指尖磨穿了 |
| 神性 vs 生活感 | 被供奉的神，在剥橘子 |
| 尺度 vs 尺度 | 很小的人，很大的一件东西是她的（不是武器——可以是一把椅子、一件斗篷、一只动物） |
| 时间 vs 时间 | 和服的形制，运动鞋的鞋底磨损方式 |

**检验**：矛盾的两端能不能各自指到画面上的一个具体位置？指不到就只是设定，不是设计。

## M3 · 从尾部取样 Pick from the Tail

**解决什么**：每个属性都是它那个分布的众数（银发红瞳黑裙）。

**AI 默认**：第一个想到的就是最可能的，最可能的就是最多人用过的。

**设计师**：知道自己的第一反应是训练出来的，所以不信任它。

**手法**：
1. 对下列属性中**至少一个**（越核心越好）：发型/发色 · 主轮廓 · 配色 · 主道具 · 姿势。
2. 快速写下最先冒出来的 3 个选项。
3. **全部丢弃**。
4. 第 4–6 个里挑一个，或者从相邻领域借一个（服装史、建筑、生物、器物、职业工具）。
5. 剩下的属性可以留在众数——**不要全部尾部取样**，那是另一种平庸（"为怪而怪"）。

**例**：
- 头发：丢弃「银色长直」「黑色长直」「粉色双马尾」→ 取「只有一侧留长、另一侧贴头皮编成祭祀纹样，颜色是褪色的旧象牙」
- 主道具：丢弃「剑」「法杖」「书」→ 取「一只比她躯干还长的木质量尺」
- 配色：丢弃「黑金」「白蓝」「黑红」→ 取「未漂白的生丝色 + 墨黑结构 + 一点氧化铜绿」

**检验**：这个属性在 Danbooru 上是不是有 10 万+ 张图？是的话它就在众数区。

## M4 · 建因果链 Build Causality

**解决什么**：姿势、服装、道具、环境各自独立随机，"看起来像贴上去的"。

**AI 默认**：`holding sword, standing, wind, petals` —— 四个独立事件。

**设计师**：画面里每一样东西都是另一样东西的**结果**。

**手法**：写出至少两个"因为"，并且这两个"因为"必须能在画面里看到证据。
```
姿势 ← 道具：她单肩下沉，因为背上的东西是偏的
道具 ← 职业：背上的是编织用的经轴，因为她是织工
服装 ← 职业：袖口束紧到肘部，因为织机会绞袖子
磨损 ← 习惯：右手食指有老茧和线勒痕，因为她总用这根手指绷线
环境 ← 时间：地上的光是从很低的窗进来的，因为她天不亮就开工
```
Prompt 里用具体空间关系词表达因果：`weighed down on one shoulder by`, `sleeve bound tight at the elbow`, `callus on the right index finger`, `light from a low window`。

**检验**：随机删掉画面里一件东西，别的东西会不会"解释不通"？会，就说明有因果。

## M5 · 选一个瞬间 Choose the Moment

**解决什么**：角色处于"状态"而不是"时间"里——站着、看着、存在着。

**AI 默认**：`standing, looking at viewer, gentle smile`。这是证件照。

**设计师**：抓动作发生**前或后 0.5 秒**，让画面有前史和后果。

**手法**：
- 之前 0.5 秒：手已经伸向，但还没碰到；刚要转身，头先动了；正在吸气准备说话
- 之后 0.5 秒：刚放下的东西还在晃；刚摘掉的手套还在另一只手里；刚坐下，裙摆还没落定
- 打断：正在做 A，被 B 打断，视线离开了 A 但手还在 A 上

**例**：
- ✗ `holding a teacup, smiling`
- ✓ `has just set the cup down too hard; tea is still rocking; she is looking at the door, not the cup`

**检验**：能不能说出画面前 1 秒和后 1 秒分别发生了什么？

## M6 · 做减法 Subtract

**解决什么**：靠"加"达到完成感，结果是均匀的噪音。

**AI 默认**：担心不够，所以再加一条腰带、一对耳环、一层光效。

**设计师**：完成 = 再拿掉一样东西就会破坏命题。

**手法**：
1. 列出当前设计里的全部元素（服装件、配饰、道具、背景物、光效）。
2. 逐个问："删掉它，命题（M1）还在吗？"
   - 在 → 删。
   - 不在 → 留。
3. 对留下的每件东西问："它和 M1 的痴迷点是同一套形态语法吗？"（都是骨？都是布的褶？都是直线？）
   - 不是 → 改成同一语法，或删。
4. **写下删掉了什么**。这行字会出现在 Brief 里，是给用户看的：它证明有人做过判断。

**优先删除清单**（这个用户的历史反馈里反复出现的冗余）：手表/怀表 · 随机项链耳环 · 装饰性腰带与绑带 · 蝴蝶 · 玫瑰 · 魔法阵 · 发光粒子 · 飘落花瓣 · 无来源的 rim light · 第二件武器

**检验**：设计里每一件东西你能不能说出"它为什么在这"？说不出的，删。

## M7 · 留一处怪 Keep One Strange Thing

**解决什么**：处处安全 → 处处可预测 → 没有人记得住。

**AI 默认**：优化"不出错"。所有东西都在审美安全区。

**设计师**：知道记忆点来自**轻微的违和**——一个评审委员会会投票删掉的细节。

**手法**（只选一处，多了就是乱）：
- 比例怪：一只袖子长到拖地、领子高过下巴、鞋头长得不合理
- 材质怪：礼服用的是粗麻、盔甲的一块是纸糊的、宝石是磨砂的不发光
- 位置怪：耳饰戴在耳后而不是耳垂、腰带系在胸下、手套只戴半只
- 行为怪：拿道具的方式不对（倒着拿书、握剑鞘不握柄）
- 状态怪：完美的妆，一只眼睛的眼线花了；崭新的衣服，一处补丁的针脚是另一种颜色

**边界**：怪必须仍在 `personal-identity-profile` 的签名内——精致、略带危险、有理由的不对称。怪不等于丑，不等于随机，不等于"为了不同而不同"。它应该像一个**人的习惯**，而不是一个 bug。

**检验**：把这一处遮掉，设计会不会立刻变得"正确但无聊"？会，就留对了。

## M8 · 不均匀分配密度 Uneven Density

**解决什么**：装饰均匀撒满全身，视线没有落脚点。

**AI 默认**：每个部位都有东西——头饰、耳饰、项链、胸饰、腰饰、手饰、腿饰、鞋饰。

**设计师**：一处密到看不过来，一处空到可以呼吸。密与空的**对比**就是节奏。

**手法**：
1. 指定**一个密集区**（头部/胸口/腰部/背部/一只手/裙摆——五选一）。所有母题重复、材质对比、细部刻画都集中在这里。
2. 指定**一个安静区**（通常是密集区的对角：密在头 → 安静在腿；密在腰 → 安静在肩颈）。安静区只有大块面、单一材质、单一颜色。
3. 两个区之间用一条**视觉动线**连接（一条长带、一道开衩、一支长杖、一缕头发）。
4. Prompt 里明写：`ornament concentrated around ___ ; ___ left plain in a single unbroken ___`

**检验**：缩成拇指大的缩略图，能不能一眼看出"重的地方"在哪？

## M9 · 命名刺点 Name the Punctum

**解决什么**：多处高饱和互相抢戏，或者根本没有一个视线终点。

**AI 默认**：红瞳 + 红丝带 + 红宝石 + 红指甲 + 红花——"主题色"均匀分布。

**设计师**：基底约 70%、结构色约 25%、刺点 ≤ 5%。刺点是**一个**位置，是视线的终点，通常也是叙事的钥匙。

**手法**：
1. 先定基底和结构色（这个用户的签名：浅色/生丝/象牙/雾灰基底 + 墨黑/深褐/炭色结构）。
2. 刺点选一个**有叙事意义**的位置：
   - 眼睛（她在看什么）
   - 手里的东西（她在做什么）
   - 一处伤口/一滴/一线（发生过什么）
   - 唯一的一件饰物（她是谁）
3. 刺点的颜色和其它任何地方都不重复。
4. Prompt 里用精确位置词：`the only saturated color is the ___ at ___`

**检验**：闭上眼再睁开，第一眼落在哪？如果不是你指定的刺点，重做。

## 动作之间的关系

```
M1 痴迷点 ──决定──▶ M8 密集区在哪 ──决定──▶ M9 刺点在哪
   │
   ├──决定──▶ M4 因果链的起点
   │
   └──约束──▶ M6 删什么（不服务 M1 的都删）

M2 矛盾 ──提供──▶ M7 那一处怪的最佳来源
M3 尾部取样 ──提供──▶ 轮廓策略的候选
M5 瞬间 ──激活──▶ M4 的因果在画面里可见
```

如果时间只够做三个：**M1、M6、M7**。有中心、有删减、有一处怪——这三样在，就不会是 AI 味。
