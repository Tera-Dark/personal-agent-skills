# Anti AI Design Patterns

## Purpose

Prevent generic model-like creative decisions.

## Common Failures

- Adding random accessories without purpose
- Using complexity as a replacement for design
- Creating beautiful but anonymous characters
- Ignoring personality in poses and expressions
- Overusing cyber, mechanical and tactical elements

## Correction Principles

Prefer:

- clear character identity
- meaningful visual motifs
- emotional expression
- coherent costume language
- memorable silhouette

A strong design should feel intentional, not assembled.
