# Modern Poster Design Grammar — 现代艺术海报视觉语法

> 2026-10-07 personal taste calibration. This is a user-specific design layer for crossover posters, game key visuals, cinematic posters, title-driven character posters, dreamcore/labyrinth posters, and other illustration-led graphic works.
>
> Primary calibration: the user's recent analysis of Reverse: 1999 poster design. The goal is not to imitate Reverse: 1999's surface style, but to reproduce its **concept-first visual planning discipline**.

## Core thesis

**A poster is not an illustration with a title added afterward.**

For this user's target, the poster itself must be conceived as a graphic artifact:
**visual concept → graphic structure → character role → environment / object relationships → typography → rendering**.

A successful poster should still communicate its core idea when the title and small decorative details are removed.

## 0.5 Anti-Mediocrity Preflight

Reject any poster concept that can be summarized as:
**character + genre mood + scenic background + title**.

Before execution, the concept must pass:
- **swap test**: changing the character breaks at least one major visual relationship;
- **removal test**: removing the central object / graphic device destroys the poster identity;
- **thumbnail test**: core shape and hierarchy survive without typography or micro-detail.

For this user, a crossover poster normally needs:
**one visual metaphor + one macro graphic device + one character-specific action / relationship**.

## 1. Concept first, character second

Before designing the character placement, answer:

> What is the one visual idea that makes this poster memorable?

The idea must be expressible as a concrete noun + action / relationship.

Good:
- "A wine cup contains an impossible dream city."
- "A school ceiling has become the sky while the floor reflects a childhood home."
- "A red hood becomes the geometric frame of the entire poster."

Weak:
- "A beautiful cyberpunk portrait."
- "An atmospheric fantasy poster."
- "A stylish character in a movie world."

The latter are moods, not designs.

## 2. Cross-IP fusion must be conceptual

Do not solve crossover design as:
**character + IP costume + IP background**.

Find the intersection between the two IPs:
- shared symbol;
- shared narrative concept;
- shared object;
- visual contradiction;
- cultural collision;
- material transformation;
- scale transformation.

Then turn that intersection into one poster device.

Example:
**Ling × Inception** is not "Ling in a modern dream city."
It can become **"a wine cup containing a folded dream world"**, combining Ling's wine/poetry symbolism with Inception's nested impossible space.

The crossover should feel difficult to separate afterward: removing either IP should weaken the concept.

**Reject costume-swap fusion:** if the crossover is only a costume, logo, background, palette or a few props, the concept is unfinished.

## 3. Graphic mass hierarchy

Design the poster as large masses before details.

Start with:
1. one dominant visual mass / container;
2. one character mass;
3. one counter-mass or supporting structure;
4. one quiet field.

Useful structures:
- giant object as frame;
- oversized face / portrait fragment;
- circular or elliptical container;
- architectural block;
- diagonal ribbon / cloth / road;
- split reality / mirrored field;
- large title block;
- cropped foreground object.

Character scale is not inherently "better" when larger. What matters is **hierarchy**:
- small character + giant concept = intentional scale contrast;
- medium character + giant graphic object = graphic poster;
- large character + compressed environment = character key visual.

Never use "make the character bigger" as the only fix for weak poster impact.

## 4. Scale contradiction

Use at least one deliberate scale relationship:
- oversized object + normal character;
- tiny secondary figure + monumental character;
- giant typography + small object;
- giant environment fragment + cropped body part.

Scale must explain the concept, not exist as random surrealism.

## 5. Directional and geometric composition

A poster needs a readable macro path.

Choose one primary construction:
- radial / orbit;
- vertical spear;
- diagonal thrust;
- S-curve;
- circular container;
- split-plane;
- central vanishing point;
- asymmetric cascade.

Then make 2–4 major elements obey that geometry.

Do not let hair, props, background effects and typography each create independent directions.

## 6. Typography is a graphic element

When the user asks for a title / logo / IP name:
- integrate typography into the composition rather than treating it as an afterthought;
- let architecture, objects, frames, lines, shadows, or negative space interact with the title;
- choose placement as part of the visual hierarchy;
- use title scale deliberately;
- allow partial cropping, overlap, weathering, registration shift, diagram lines, archival labels, or environmental integration when conceptually justified.

Text should participate in the image's structure, not merely identify it.

Important:
- Do not claim exact brand typography replication unless the system can actually render / verify it.
- Prefer "title typography", "condensed serif", "geometric lettering", "archival lettering", etc. as controllable visual instructions.

## 7. Character role inside the poster

The character must perform a visual job:
- anchor the composition;
- break the frame;
- scale against a monumental object;
- activate a negative-space field;
- connect foreground and background;
- become part of a symbolic object;
- provide the main face / emotional punctum.

The character is not automatically the whole composition.

## 8. Pose: OOC-safe action

For known characters:
- preserve signature body language and personality;
- use a quiet action that follows from the character's role;
- let the pose interact causally with the poster's central object or structure;
- avoid generic "standing hero pose", random combat pose, seductive posing, or exaggerated reactions unless canonical.

A strong poster pose usually describes a **specific 0.5-second moment**, not a static category.

## 9. Environment is a designed support system

Background elements must serve one of:
- scale;
- depth;
- story;
- geometry;
- color mass;
- typography integration;
- symbolic meaning.

Do not fill the page with "cinematic environment" words.

For dreamcore / surreal posters, prefer **one primary spatial contradiction** rather than a pile of disconnected uncanny objects.

Examples:
- ceiling = sky;
- floor reflection = another place;
- doorway = white void;
- architecture bends only once along the main axis;
- object contains a miniature world.

## 10. Uneven density

Poster detail must be intentionally uneven:
- high-density pocket around face / central object / title interaction;
- medium-density support region;
- quiet field for contrast.

Do not texture every surface.

The empty area is part of the design.

## 11. Punctum and color discipline

Choose one primary punctum:
- object;
- face;
- red fabric;
- glowing symbol;
- title;
- reflected shape.

Use 3–4 major color masses.
One accent color should repeat structurally rather than multiplying into unrelated accents.

## 12. Designed irregularity

A strong poster may contain one controlled "wrong" or uncanny element:
- impossible reflection;
- scale mismatch;
- title partially submerged / weathered;
- architecture rotated;
- object behaving like another material;
- secondary reality inside a container.

Keep this to one dominant contradiction unless the concept itself requires more.

The strange element must amplify the concept, not replace beauty, anatomy, silhouette, or readability.

## 13. Poster vs ordinary illustration diagnostic

Before compiling the prompt, ask:

1. Can I name the poster's one visual concept in one sentence?
2. If the title is removed, does the composition still have a designed identity?
3. Is there a deliberate graphic mass / geometric structure?
4. Is the character performing a clear compositional role?
5. Is there a meaningful scale or spatial contradiction?
6. Does typography interact with the image rather than float above it?
7. Is there a clear quiet field?
8. Does the pose remain believable for the character?
9. Are the crossover elements fused through a common idea rather than pasted together?
10. If decorative atmosphere is removed, does the design still work?

If 1–3 fail, do not add rendering detail. Return to concept and macro composition.
If 4–6 fail, redesign the graphic relationship.
If 7–10 fail, simplify and rebuild causality.

## 14. User-specific anti-patterns

Do not default to:
- character centered + scenic background + logo at top;
- character tiny in a huge environment with no intentional scale relationship;
- random neon / particles / petals / bokeh as "artistic" filler;
- giant cinematic adjectives without geometric decisions;
- generic crossover costume swap;
- title pasted into empty sky;
- beautiful character + cinematic environment + floating logo with no graphic relationship;
- five different surreal objects with no shared logic;
- highly detailed rendering on top of a weak thumbnail;
- making the character more provocative or heroic when the source character would not behave that way.

## 15. Preferred workflow

For crossover poster requests:

**IP intersection**
→ **one-line visual concept**
→ **3 candidate concepts**
→ **reject 2**
→ **graphic mass / geometry**
→ **character role + OOC-safe moment**
→ **scale contradiction**
→ **density map**
→ **punctum**
→ **typography interaction**
→ **rendering / artist stack**
→ **compact NAI5 prompt**

The artist stack is downstream. Do not let artist selection determine the poster concept.

## 16. Calibration examples from this session

### Perlica × Death Stranding
Weak approach:
- character in a bleak landscape;
- courier equipment;
- title at top.

Improved approach:
- character as a high-fashion courier;
- lower-right character / environmental scale;
- rain, cargo and rope become costume geometry;
- poster is structured around delivery / loneliness / connection.

### Ling × Inception
Successful concept:
- giant wine vessel as central graphic container;
- impossible dream city exists inside the wine;
- Ling sits on the rim;
- typography and circular diagram lines share the same geometric system.

This worked better because **the crossover concept became the composition itself**.

### Amiya × Silent Hill / dreamcore
Successful concept:
- "an abandoned school where the ceiling is sky and the floor reflects a childhood home";
- character waits quietly at the center-right;
- repeated doors, impossible classroom, water reflection, and title create one spatial contradiction.

This worked better because the dreamcore feeling came from **one coherent spatial error**, not a collection of horror props.
