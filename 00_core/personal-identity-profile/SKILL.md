# Personal Identity Profile

## Purpose

A persistent identity layer describing the user's long-term creative preferences, goals, and workflow habits.

This skill does not generate prompts. It provides context for creative decisions.

## Usage

Before creative generation tasks:

1. Read user preferences.
2. Apply preferred aesthetics.
3. Avoid known dislikes.
4. Match output style and workflow expectations.
