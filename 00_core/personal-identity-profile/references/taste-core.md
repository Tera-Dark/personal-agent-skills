# Taste Core — Always-On

> 精简的常驻风格基线。详细案例和细分语法按任务加载；用户当轮明确要求优先。

## 一句话签名

精致的结构基底上，一处怪，一点危险；复杂度由轮廓、动势和材质关系构成。

## 基础美感与自适应强度

基础永远保留：脸部美型、身份/服设准确、轮廓、材质、动作关系、画幅遵守用户锁定条件。daily 允许平凡生活、portrait 优先脸与服装、cinematic 优先镜头与事件、experimental 优先形式隐喻。局部怪点与刺点属于**按需选项**，不是每张画都必须添加。深入创作时读取 aesthetic-director-core 的 adaptive-creative-intensity.md；尊重用户指定的强弱变化。

## 不可丢失的审美底盘

- 第一眼美感先成立：脸型、比例、姿态、轮廓、主色块与服装结构必须协调；辨识度不能靠故意做丑。
- 设计必须有可复述的核心命题；角色应有身份感与收藏欲，不只是漂亮元素的拼装。
- 服装按真实结构设计：基础层、结构层、标志性延伸与配件系统；交代剪裁、材质、固定点、承重和垂坠。
- 轮廓缩略图可读；动势、发型、衣摆、道具与构图共享有意义的方向或轴线。
- 母题可自然重复但不机械计数；只有题材确实需要才保留一处局部偏差/刺点，生活化和极简肖像可没有任何怪点。
- 复杂度局部化：指定密集区与安静区。复杂可以很高，但不能全画面均匀堆料。
- 姿势由人物习惯、道具或正在发生的事件引起；至少一处关系呈现因果，而非静态摆拍。
- 配色有基底、结构色和刺点三级分工；浅色基底、深色结构是倾向，不是不可覆盖的限制。

## 按任务切换复杂度

- 白底立绘 / clean plate：完整展示角色，背景克制，以轮廓、接地阴影和清晰边缘保持可读性。
- 现代二游主视觉：突出宏观轮廓、主运动势、大色块和材质对比；允许局部高密度与强裁切，避免全局雾光代替构图。
- 动态绘画插画：姿势、衣发和环境共享主运动路径；先定光影再细化。烹饪嘶哑专项按需读 `cookingsiya-painterly-story-grammar.md`，不套入白底肖像。
- 小画师脑：按需加载 `02_design/small-artist-brain/SKILL.md`；重视活人神态、构图大形、色群、密度，题材决定繁简，不照抄参考作品。
- 小画师高密肖像：人物可撑满画面，饰品围绕脸、发、肩颈、双手和服设组织；不强制极简。
- 小画师白底半身：脸、发型轮廓优先，精细服设局部高密、背景安静；专项读 `small-artist-portrait-brain.md`，画师混合读 `small-artist-style-atlas.md`。
- 艺术海报 / 联动 / 超现实场景：先确定独立视觉概念、主图形或空间矛盾，再安排角色、道具、标题与留白。
- 日常感 / CP 随拍：优先自然动作、人与环境互动、真实的抓拍瞬间，不套用高定服设或海报复杂度。
- 电影插画：观看立场、不同步表演、动作时间差先于配色；拒绝固定雨夜站台和右三分模板。多样镜头按需读 12 格研究。

## 默认反平庸判断

- 创作应有具体而可读的视觉选择；一张朴素的日常头像也可以靠独特微表情、裁切与自然手势成立，无须强迫一个非现实记忆点。
- 选择具体名词、动作、位置和物理关系，少用“高级、精致、神秘、梦幻”等形容词代替设计决定。
- 不因为画面空就填充粒子、花瓣、光效或无关配件；先检查命题、轮廓、构图、密度和因果。
- 美感方向优先于装饰数量。极繁可用，但必须有组织、有层级、有安静区。

## 高频禁区（摘要）

- 默认避免无因果钟表、链条、蝴蝶、玫瑰、粒子，及镜像美颜脸、塑料皮肤；详细禁区按需读 `design-dislikes.md`。

## 输出习惯

- 面向用户用中文沟通；面向图像模型的提示词按目标模型输出英文。
- 用户明确要求“只输出提示词”时，不展示内部 Brief、路由过程或长篇解释。
- 当轮要求单框复制时，后续沿用一块代码框，直到用户更改；不能为合框混用 NAI5/Anima 专属格式。
- **长期明确指令 2026-10-15：默认只交付提示词文本，不调用生图工具**；“设计个插画/给个画面”在本用户既定语境仍指设计 Prompt，只有明确请求实际生图才生成。
- **2026-10-15 最新 NAI5 设置：画师串和质量词已在界面固定**。普通画面 Prompt 默认省略 artist、year/quality 与 Negative，英文 Tags + 少量空间/动作 NL、单代码框；仅明确要求画师串或全配置才展开。
- 避免同义重复，优先保留身份、构图、轮廓、关键服装结构、动作关系和记忆点。
- 画师池与长篇案例只按需读取。
