# 小画师脑的实战检验与回归案例

> 审美体系能否迁移，靠**跨题材**测试，不靠在同一题材上堆词。以下为原创设计蓝图示范，不是对 16 张原图的改写。可以用作后续用户跑图 A/B 的目标，不能冒充已测试过的模型表现。

## T1 — 白底单人半身（克制）

**命题**：看似端庄的少女被一只偷走耳环的小鸟逗得失去冷静。
- 主体：7 分身近景，脸在偏右上，左侧鸟翼占比小；单色奶白空白占 35%。
- 行为：她一手停在耳边，另一手半抬追小鸟；眉上挑、嘴角忍笑，发尾有轻微失衡。
- 色块：乳白/深墨绿服饰/暖肤，耳环是唯一金色强调。
- 密度：脸—耳—鸟爪；远离此区的裙摆大形概括。
- 审美检验：没有繁花照样成立；不是标准定睛坐姿。
- 不可接受：给鸟随意添加 20 朵花、漂浮魔法钟，形成无因果精美背景。

## T2 — 德哈日常双人（冲突互动）

**命题**：一场小争执在谁先松手的问题上变成暧昧。
- 主体：横版略低机位，两人肩与前臂相交构成错位 Z 形；桌面只留一杯饮品。
- 行为：德拉科嘴硬递错杯，哈利抓住他的袖口反击；德拉科依然保持刻薄笑意但眼神停住，哈利笑得像刚赢了一局。
- 色块：咖啡暖奶白作安静背景，黑衣/墨绿作结构，暖橙脸手为表情锚点。
- 密度：脸、袖口、杯沿；墙不需满铺画片。
- 审美检验：离开“bl”标签仍能从身份差异、动作承接看出感情。
- 不可接受：双人面对镜头并排、两张美型脸同时脸红、无承重的“壁咚”摆拍。

## T3 — 两人幻想叙事（高密度）

**命题**：两位互不信任的旅人同时按住一张会自行翻页的旧地图。
- 主体：上方巨大拱框，下方二人一低一高围着地图形成三角；飞动地图页沿斜对角连接视线。
- 行为：左人压住纸边，右人把火光移近查看，二人的目光先落在共同目标，随即互相碰见。
- 色块：青绿深色结构、暖黄纸与火、微量紫蓝作为冷暖刺点。
- 密度：火—手—图纹最密，背后拱框和暗色衣摆退后。
- 审美检验：极繁来自共同物体、结构和物理场景，并非美术素材堆积。
- 不可接受：给画面加三只无用猫、五个时钟、遍地高亮花瓣掩盖地图读不清。

## T4 — 深色单人冷感肖像（低色数）

**命题**：她在听见自己名字的瞬间回首，额发遮住一只眼。
- 主体：方图，脸偏上中，黑发一块大形；后景冷白，没有完整室内布景。
- 行为：轻微转肩，眼镜滑了一点，嘴唇准备答话，手碰到衣领。
- 色块：黑 / 冷白 / 灰绿眼睛，面部很少暖色。
- 密度：发丝关键交点与眼镜耳侧精细，其余宽线和柔块概括。
- 审美检验：删去花鸟装饰仍保留强辨识、非“AI 标准表情”。

## T5 — 古风女性动态半身（优雅而不僵）

**命题**：她差点被突然吹起的袖子遮住茶盏，于是低头按住杯口。
- 主体：4:5，略俯视，中近景；脸与手、杯沿形成短三角，衣袖一条长斜线。
- 色块：淡豆绿/米白/少量胭脂粉；局部墨色衣领定骨。
- 动作：肩头与袖褶顺风落下，手腕自然弯曲，杯由另一手托稳；眼睛不是正对观众。
- 密度：眼、手、杯沿，底部薄墨山景只做安静块。
- 审美检验：衣袖动线因风产生，杯有真实支撑。

## 新增 12 图审美校准的原创压力测试（2026-10-12；未实际跑图）

### T6 — 极窄竖幅 × 安静寓言（不要强行剧情动作）
**命题**：一位年轻植物档案员发现自己照顾的无名树苗，影子竟长成了多年后的苍老形态。
- 主体：约 1:2.6 纵向，顶部巨大旧窗暗形形成压迫，中段人脸和双手护住的幼苗最清楚，底部浅色围裙与地面的影子逐步展开、变得安静。
- 关键：寓意通过主体/影子尺度并置成立，不强塞挥手、大笑或大群发光鸟。
- 验收：缩略图能读出暗→亮、上→下的节奏，影子与幼苗在空间里有可解释的位置。
- 不可接受：照搬骷髅守护白衣少女／花团圣龛的具体布置。

### T7 — 宽幅自然日常 × 双人距离（不要每次靠拥抱）
**命题**：出门远行前，一位姐姐蹲下帮弟弟系紧滑落的行李带，弟弟把准备好的车票藏在身后不让她看见。
- 主体：宽 16:9，人物偏左下，右侧是开阔码头与大片安静天空，风使布带与衣角沿斜线指向远处渡轮。
- 关键：蹲姿承重、触点、隐瞒的手与目光关系；装饰总量少，色彩以灰青海面/深蓝旅行衣/暖皮肤分组。
- 验收：去掉人物美化词与装饰物仍能从身体动作读懂关系和出发前的瞬间。
- 不可接受：让两人并排盯镜头、放一堆花和鸽子填补右侧空海。

### T8 — 横幅编辑式双区 × 真实留字安全区
**命题**：一名古董修复师在维修站把最后一片带海盐痕迹的船钟碎瓷放回盒中，旁边留有一幅极小的物件截面图。
- 主体：总画幅 2.4:1，左侧 65% 人物+工作台叙事主图，右侧 35% 净色纸白区预留标题与唯一插图；右区必须在构图阶段预留，不让发丝和碎片侵入。
- 光：左上天窗光，手、瓷片受光；服装与墙面大块概括，主形可读。
- 验收：分别遮住左右区仍有完整的主图和独立排版区；**NAI 输出先做无长字内容图，准确文字由后期排版**。
- 不可接受：单纯全幅画完后在角落叠乱码金字、照搬蓝白双人纪念海报。

### T9 — 高调白衣 × 可控失边（不是糊图）
**命题**：午后暴雨将停，舞台道具师抬起湿透的白布，布后露出一道恰好像门的光。
- 主体：4:5，白布占据画面约一半但不能抹掉承重手与肩；湿布一部分融入强窗光，另一边仍能靠阴影/褶皱被识别。
- 焦点：被布拉紧的指节、眼睛、固定在袖口的别针；灰绿的棚内深处提供承重暗块。
- 验收：光有物理来源、布料有重量，失边仅发生在光照强区，其余关键轮廓清楚。
- 不可接受：全图发白、无明暗结构、随机长发/花瓣代替风向。

## 评审 Gate（每项 0/1/2，总 16）
1. 视觉命题：泛题材 0 / 有动机 1 / 不可替换、缩略图可见 2。
2. 人物活性：僵硬 0 / 单一动作 1 / 性格×表情×物理因果 2。
3. 大形：散乱 0 / 有主体 1 / 明确两三个相互制衡的大质量 2。
4. 色彩：随机 0 / 配色和谐 1 / 彩度、冷暖、暗色承重各有角色 2。
5. 密度：均匀 0 / 有疏密 1 / 主精—次精—弱精可定位 2。
6. 环境/道具：装饰 0 / 说明地点 1 / 直接承接动作和构图 2。
7. 识别与气质：模板脸 0 / 身份可辨 1 / 有独特反应且锁定身份 2。
8. 变化与原创：单一公式 0 / 略有差异 1 / 根据题材做结构变化而不复刻参考构图 2。

**建议通过线：** ≥12 且第 2、7 项不能为 0；用户如果明确极简，则以减少细节仍满足第 5 项为优，不强制高繁。该数字只是内部自检标尺，不是对画师本人的评审。
