# Illustration Direction

## 定位

输入：Creative Brief（来自 `aesthetic-director-core`）+ 可选的角色 blueprint（来自 `character-design-engine`）。
输出：一份**作者化的画面 blueprint**。适配器只需翻译，不需要再决定“人放哪、为什么这样构图、环境怎么参与叙事、留多少白”。该 blueprint 必须通过类型专属 Blueprint Gate 后才能进入模型适配器。

插画和立绘的区别：立绘展示角色，插画捕捉**一个被设计过的时刻**。因此现在的第一决定不是“背景是什么”，而是：

> **这张图的画面命题是什么？**

画面命题必须能够在一句话里描述一个视觉关系，而不是一个泛泛的题材：

- “一个很小的人被巨大的银色拱门连续框住。”
- “白发像河流一样铺满水面，人物只是一处静止的源头。”
- “婚礼已经结束，只剩空椅子和迟到的人。”

如果只能写成“漂亮的神殿 / 梦幻花园 / 华丽场景”，说明画面还没有被设计。

## 来自 Evidence-Based Taste Gate 的视觉举证（2026-10-21）

导演调用 `00_core/aesthetic-director-core/references/visual-taste-evidence-protocol.md` 时，本模块承接幸存方案，**用实际可见的动作接触、主构图形、明度/距离、遮挡/材料、真实光源证明命题**；不接受仅在文字里解释悲剧、命运或神性。内部保留 `visual_evidence` 和 `interpretation_status`（正典 / 推断 / AU / UNKNOWN），传给 Visual Prompt Core 的只有可画的事实。不要沿用前图布景或替用户补黑液/天使；纯美型图不需故事。没有实际图时只可做文本预测，不能称视觉缩略图已通过。

## 硬规则

- **先有画面命题，再有瞬间，再选观看立场与机位，之后才排空间和构图。** 摄影机不是为已摆好的立绘补一个角度；镜头位置必须实质改变人物关系、透视、遮挡、裁切或情绪。
- **每个插画镜头须有 Camera Intent：谁在看、在哪看、为什么是这一秒。** `cinematic composition`、孤立的 `slightly elevated`、任意焦段数字不构成镜头设计；摄影论证见 `references/cinematic-camera-grammar.md`。
- **风格与电影感分开判断（2026-10-14 用户 12 镜头校准）**：电影感不是雨夜、车站、蓝橙撞色、镜头眩光、右三分线的固定配方；须先决定观众的观看权限、人物不同步的活人反应、画面以外的时间。写实抓拍、黑白压暗、高调失边、卡通图形、群像和强近景均可成为电影语言。按需读 `references/cinematic-12-frame-study-2026-10-14.md`。
- **人物是否居中、看镜头、占满画面取决于真实的构图任务。**
- **环境必须做事，纯白留白也合法。** 不得擅自添加景物。
- **一个能支持构图的主视觉母题，优先于无关装饰。**
- **光必须有物理来源。** 一个主光源 + 方向 + 衰减 + 阴影沉降区。禁止无来源 rim light。允许**有目的的局部失边**：白衣可融入透窗高光、暗发可融入深背景，但至少保留脸/手/关键动作的识别通路；不能用全图过曝或柔焦掩盖结构。
- **背景只保留能解释光、动作、尺度或叙事的层。** 窗 + 城市 + 星空 + 花园 = 多层无关背景 → 删除到只剩真正参与画面的部分。
- **氛围元素默认不加。** 花瓣、粒子、光点、蝴蝶、星尘、随机晶体不是“空白填充物”；如果删掉它们画面就崩，说明构图本身还没成立。
- **允许受控遮挡。** 前景建筑、椅背、花枝、镜框、布料、阴影可以切入人物轮廓；完整展示人物不是插画的默认目标。
- **按题材组织密度与安静区；简单肖像允许整体低密度。**
- **画幅不能只是一串长宽比。** 极长竖图优先核对上→中→下的视觉接力；横幅优先确定人物关系与横向大形；若是纪念/图文海报，开画之前预留不妨碍主图的标题/副图安全区，精确文案留给后期。
- **色彩先做大色块，再做局部颜色。** 通常控制在 3–4 个主要色彩质量 + 1 个有意义的强调色。
- **超现实一次只解决一个问题。** 一个 coherent impossibility 胜过十个随机魔法特效。

## Artist Eye · 接收跨媒介视觉方向（按需）

若上游 `aesthetic-director-core` 的 Creative Brief 已通过 Artist Eye 三向竞争，**只接收幸存方向**，把其主视觉因果落实到本模块现有的观看立场、前中后、遮挡、形状、光和密度。不能重开平行的三案，也不把动画/建筑/版式等参考误做成固定场景道具。对于静态抽象或编辑封面，`camera intent` 可合理解释成观众的版式阅读顺序；对于场景和人像仍要求可见机位证据。优先使用上游已经记录的「删除关键关系后会损失什么」作为 Blueprint Gate 的加严检验。

## 近期校准（按需）

本轮近期要求：**IP 剧情先核实人物传再设计同人瞬间**；双格人物面部大特写须在两格间有动作/情绪增量；古风小画师近景应在美型之外有自然场景与可信互动；矿物/水墨淡入人物要保住肩颈和躯干识别，不是只剩头。按需读取 Identity 的 `00_core/personal-identity-profile/references/session-feedback-2026-10-14-15.md` 逐项证据与作用域。常规电影感不自动加双格、雨夜、文件、黄伞或矿物裂纹。

## 执行流程

```
Step 0  画面命题      一句话说明这张图最核心的视觉想法；禁止只写题材或“漂亮场景”。
Step 1  瞬间/状态     选叙事温度：安静停留 / 微动作 / 戏剧动作 / 寓言并置或编辑画面。动态画面问前后 0.5 秒；静态寓言/展示画面可只锁定有意义的视觉关系，不虚构剧情。
Step 2  视觉母题      选一个承担框、切、连、引导、反射、缩放或遮挡功能的核心形状/物件/材质。
Step 3  观看立场      决定摄影机作为谁的视角：亲密见证、旁观、角色主观或正式肖像；必须写出情绪上的作用。
Step 4  机位与瞬间    选摄影机相对人物的侧向/高度/距离，选择动作中哪个具体相位被定格；从机位推出近大远小、透视与可见部分，避免事后补 `low angle`。
Step 5  人物调度      前/中/后层、身体重心、目光、牵手与承重支点；指定一处有意义的前景遮挡，双人图明确 A→B→A 的视觉反应。
Step 6  画幅与裁切    人物占比、画幅、越界裁切、主体比例；用真实摄影位置决定该出现哪些服饰细节。近景大脸与全身完整展示不能同时强锁。
Step 7  主构图形      将上面机位产生的肩线、手臂、发丝、衣摆与留白组合为大形、对比质量及观众视线路径；如果换成正面平视依然没有变化，回到 Step 3 重选机位。
Step 8  主光源          一个。位置、方向、色温、衰减；阴影沉降区必须存在。第二光源只有在与主光形成明确主题关系时出现。
Step 9  密度图          密集区 / 安静区 / 连接两者的动线；安静区通常是大块单一材质的墙、天、地、水或布。
Step 10 叙事残留       环境里一件东西的状态说明发生过什么：空椅、未收的物、湿脚印、断开的丝带、错位倒影、磨损地面等。
Step 11 色块策略       先定 3–4 个主要色彩质量，再定唯一强调色；避免局部颜色无限增殖。
Step 12 辨识刺点       一个令人记住的可见事实；可以是平凡日常中的反差/不对称，也可以是超现实事实，但必须与命题同源。无须为了满足字段硬塞魔法。
Step 13 氛围预设       从 references/atmosphere-presets.md 选一个（或不选）。预设只调光 / 色 / 材质 / 神态，不用来补构图。
Step 14 减法            删除随机装饰、无因果道具、无关背景层、第二视觉母题和多余光源；记录删掉什么。
Step 15 缩略图测试      想象缩小到手机缩略图：能否立刻看出大形、人物位置、视觉母题和焦点？不能则回到 Step 0–4。
```

## Blueprint Gate Contract

An illustration blueprint is READY only when visual thesis, captured moment, motif, scale/placement, **camera intent / actual vantage / foreground-midground depth / motivated crop**, environment-character relationship (or intentional white-space absence), physical light, density map, narrative residue (or consciously omitted for portrait), color-mass strategy, punctum/strange detail, subtraction decisions and locked facts are present. Camera decisions must precede final layout and be visually consequential; not merely a camera-angle adjective.

## 图文海报与编辑式版面交接（按需）

当作品不仅是插画镜头，而且需要**精确文字层级、标题安全区、页脚信息或人物穿出背景图窗**，使用 `../editorial-layout-design/SKILL.md` 设计编辑排版。职责拆分：本模块先决定人物身份、机位、动作、占比和一处主形，编辑模块只决定字与图的配重、图窗与纸面、越界遮挡、信息系统。最终本模块合并 Blueprint 并执行人物脸/手势的不可遮挡检查。

特别区分：**图像窗口边缘**和**最终画布裁切边**是两条边界。人物头发越出图窗进入纸白可以成立，人物在画布外的区域不应被要求“完整展示”。若仅借鉴杂志排版而用户只要纯插画，**不要**自动加入标题、发行日期、署名或伪造文字。

## 立绘模式（白底 / 展示板）

如果任务其实是立绘而不是插画（白底、设定图、展示板），仍走 `references/composition-patterns.md` 的景别协议；但不要把“背景空”误解为“构图空”。白底立绘可以通过轮廓、接地影、包边线、局部构造线、一个有叙事的地面物或分层展示形成版式重心。

如果用户明确要求**插画**，不得把角色重新摆成“完整角色站中间 + 风景背景”的立绘伪装。优先使用视觉母题、环境尺度、sub-framing、非对称布局、反射、切割或局部遮挡。

如果用户要求**极繁 OC 展示 / 特写垫底 / 大头贴 / 元素贴**，优先读取 `references/oc-maximalist-closeup-backdrop-preset.md`。此时“特写垫底”是核心构图骨架：巨大同角色脸部/半身特写铺在最底层，主全身立绘压在前景，再以不同尺度的大头贴、主题元素贴和局部特写形成第三层。不要把这些词误解成“增加几个装饰物”。

## 可见镜头证据的交接

镜头设计结束后，把**最近遮挡物、相对远的脸/身体、能看见的环境、承重与挺直程度、必须清晰的身份锚点**交给 Visual Prompt Core 的 `visible_geometry`；如果删去 `cinematic` 就没有空间关系，镜头不合格。完整示例和“低位镜头被误画成弯腰”案例见 `references/cinematic-camera-grammar.md` §7。NAI5 的实际 tag、正向负权重、POV 执行技巧由其 Renderer 按需读取，不能写进本设计 Skill。

## Modern Key Visual 与视觉案例

商业主视觉的大色块/焦点/动线、高清插画的建筑框景、有机包围、尺度与白底空间等详细策略，按需读取 `references/visual-grammar.md` 的补充章节；主 Skill 保留审美决策与镜头 Gate，不复制操作实例。

## 自检

- [ ] 能用一句视觉句子说明画面命题吗？
- [ ] 删除象征解释的句子后，构图/动作/视觉关系是否仍传达同样或有意多义的感受？角色动机来自可靠资料还是无证据编造？
- [ ] 动态画面能说出前 1 秒和后 1 秒吗？静态寓言/编辑海报是否有明确可见的视觉关系？
- [ ] 机位是否在布局前确定，并且能交代观看者位置、镜头侧向/高度/距离以及它改变了什么？
- [ ] 前/中/后关系、交叠遮挡、画幅裁切和重点清晰度是否由同一机位推导、彼此兼容？
- [ ] 将机位换成默认正面平视，情绪/空间/人物关系是否明显变弱？若没有则重做镜头；是否仅靠“cinematic”之类形容词撑场面？
- [ ] 有且只有一个主要视觉母题吗？
- [ ] 环境是否真的对人物做了某件事？
- [ ] 人物居中 / 看镜头 / 占满画面——如果是，理由是什么？
- [ ] 是否存在有意的尺度差？
- [ ] 是否有至少一处受控遮挡或空间切割（如果题材允许）？
- [ ] 光源有位置和衰减吗？画面里有敢于压暗或留白的区域吗？
- [ ] 背景是一层还是三层？多余层删了吗？
- [ ] 花瓣、粒子、光点、蝴蝶等是否被拿来填空？如果是，删除。
- [ ] 密集区 / 安静区 / 动线是否明确？
- [ ] 叙事残留是她造成的，还是至少与她的故事有关？
- [ ] 如使用超现实元素，是否只有一个核心怪点？不使用时是否仍然有一个独特的现实细节？
- [ ] 缩略图里能看出重的地方和视觉动线吗？
- [ ] 删除所有装饰后，画面命题仍然成立吗？
- [ ] **电影感反套路**：这一张真的需要逆光/雨夜/车站/左侧留白/右三分线吗？若去掉这些风格词还成立吗？是否有可信的观察者位置、动作时间差与独立角色行为？若没有，不靠加滤镜修复。
- [ ] 只开了一个氛围预设吗？
