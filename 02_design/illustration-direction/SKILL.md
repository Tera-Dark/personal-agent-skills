# Illustration Direction

## 定位

输入：Creative Brief（来自 `aesthetic-director-core`）+ 可选的角色 blueprint（来自 `character-design-engine`）。
输出：一份**作者化的画面 blueprint**。适配器只需翻译，不需要再决定“人放哪、为什么这样构图、环境怎么参与叙事、留多少白”。该 blueprint 必须通过类型专属 Blueprint Gate 后才能进入模型适配器。

插画和立绘的区别：立绘展示角色，插画捕捉**一个被设计过的时刻**。因此现在的第一决定不是“背景是什么”，而是：

> **这张图的画面命题是什么？**

画面命题必须能够在一句话里描述一个视觉关系，而不是一个泛泛的题材：

- “一个很小的人被巨大的银色拱门连续框住。”
- “白发像河流一样铺满水面，人物只是一处静止的源头。”
- “婚礼已经结束，只剩空椅子和迟到的人。”

如果只能写成“漂亮的神殿 / 梦幻花园 / 华丽场景”，说明画面还没有被设计。

## 硬规则

- **先有画面命题，再有瞬间，再有构图。** 构图服务于视觉命题，不是为了“好看”。
- **人物不默认居中、不默认看镜头、不默认占满画面。** 每一项都需要理由。
- **环境必须做事。** 它至少要承担框住、切割、反射、遮挡、缩小人物、制造尺度差、引导视线、承载动作或留下事件痕迹中的一项。
- **一个主视觉母题优先于一堆装饰。** 门、镜、鸟、花、长发、水面、窗格、丝带等只有在承担构图功能时才保留。
- **光必须有物理来源。** 一个主光源 + 方向 + 衰减 + 阴影沉降区。禁止无来源 rim light。
- **背景只保留能解释光、动作、尺度或叙事的层。** 窗 + 城市 + 星空 + 花园 = 多层无关背景 → 删除到只剩真正参与画面的部分。
- **氛围元素默认不加。** 花瓣、粒子、光点、蝴蝶、星尘、随机晶体不是“空白填充物”；如果删掉它们画面就崩，说明构图本身还没成立。
- **允许受控遮挡。** 前景建筑、椅背、花枝、镜框、布料、阴影可以切入人物轮廓；完整展示人物不是插画的默认目标。
- **密度必须不均匀。** 至少一个密集区、一个安静区和一条连接两者的视觉动线。
- **色彩先做大色块，再做局部颜色。** 通常控制在 3–4 个主要色彩质量 + 1 个有意义的强调色。
- **超现实一次只解决一个问题。** 一个 coherent impossibility 胜过十个随机魔法特效。

## 执行流程

```
Step 0  画面命题      一句话说明这张图最核心的视觉想法；禁止只写题材或“漂亮场景”。
Step 1  瞬间          Brief 的【瞬间】：动作前后 0.5 秒。前 1 秒和后 1 秒分别发生了什么？
Step 2  视觉母题      选一个承担框、切、连、引导、反射、缩放或遮挡功能的核心形状/物件/材质。
Step 3  尺度与人物占比 人物占画面多少？≤1/3 / ≈1/2 / ≥2/3；必须解释为什么。
Step 4  主构图形      先排大色块/几何形：主质量、对比质量、安静留白、连接动线。
Step 5  位置与视线    人物在画面哪个区域（三分线/边缘/中心）；她在看什么；留白方向由视线和命题决定。
Step 6  机位            由姿势类型和视觉命题决定；相机高度、方向、裁切、前景遮挡（sub-framing）必须明确。
Step 7  人物—环境关系  明确环境如何“作用于”人物：框住 / 遮挡 / 反射 / 缩小 / 包围 / 推动 / 分割 / 其他。
Step 8  主光源          一个。位置、方向、色温、衰减；阴影沉降区必须存在。第二光源只有在与主光形成明确主题关系时出现。
Step 9  密度图          密集区 / 安静区 / 连接两者的动线；安静区通常是大块单一材质的墙、天、地、水或布。
Step 10 叙事残留       环境里一件东西的状态说明发生过什么：空椅、未收的物、湿脚印、断开的丝带、错位倒影、磨损地面等。
Step 11 色块策略       先定 3–4 个主要色彩质量，再定唯一强调色；避免局部颜色无限增殖。
Step 12 唯一怪点       一个不寻常或超现实事实；必须与画面命题同源。
Step 13 氛围预设       从 references/atmosphere-presets.md 选一个（或不选）。预设只调光 / 色 / 材质 / 神态，不用来补构图。
Step 14 减法            删除随机装饰、无因果道具、无关背景层、第二视觉母题和多余光源；记录删掉什么。
Step 15 缩略图测试      想象缩小到手机缩略图：能否立刻看出大形、人物位置、视觉母题和焦点？不能则回到 Step 0–4。
```

## Blueprint Gate Contract

An illustration blueprint is READY only when visual thesis, captured moment, motif, scale/placement, camera, environment-character relationship, physical light, density map, narrative residue, color-mass strategy, punctum/strange detail, subtraction decisions and locked facts are present.

## 输出契约：Illustration Blueprint

```
## [画面代号]

**画面命题**：一句话说明最核心的视觉想法。
**瞬间**：她正在___。前一秒___，后一秒___。
**视觉母题**：___；它负责框住/切割/连接/反射/引导/缩放/遮挡中的___。
**画幅与占比**：竖/横，比例；人物占___，位于___（三分线/边缘/中心）。
**视线**：看向___；留白在___侧；观众视线路径为___ → ___ → ___。
**主构图形**：主质量___ / 对比质量___ / 安静区___ / 连接动线___。

**遮挡计划**：___主动切入人物的___轮廓；保留___作为识别锚点。
**主光源**：来自___，___色温，衰减到___；阴影沉降在___。第二光源（若有）：___，与主光的关系是___。

**色块策略**：主色质量___ / ___ / ___；强调色___。
**环境**：只保留___（它解释光/动作/尺度/叙事中的___）。
**叙事残留**：___
**唯一怪点**：___；它与画面命题的关系是___。
**氛围预设**：___（或无）

**留下的怪**：___
**删掉的**：___
**锁定事实**（角色 blueprint 中不可更改的）：___
```

## 立绘模式（白底 / 展示板）

如果任务其实是立绘而不是插画（白底、设定图、展示板），仍走 `references/composition-patterns.md` 的景别协议；但不要把“背景空”误解为“构图空”。白底立绘可以通过轮廓、接地影、包边线、局部构造线、一个有叙事的地面物或分层展示形成版式重心。

如果用户明确要求**插画**，不得把角色重新摆成“完整角色站中间 + 风景背景”的立绘伪装。优先使用视觉母题、环境尺度、sub-framing、非对称布局、反射、切割或局部遮挡。

如果用户要求**极繁 OC 展示 / 特写垫底 / 大头贴 / 元素贴**，优先读取 `references/oc-maximalist-closeup-backdrop-preset.md`。此时“特写垫底”是核心构图骨架：巨大同角色脸部/半身特写铺在最底层，主全身立绘压在前景，再以不同尺度的大头贴、主题元素贴和局部特写形成第三层。不要把这些词误解成“增加几个装饰物”。

## Modern Key Visual Mode

当目标是现代二游 / 商业角色主视觉时，覆盖普通“氛围图”的默认解法：

- 先做主体大形 + 主运动轴 + 支撑大形，再填人物细节。
- 用对角、S 曲线、环绕或双向张力组织头发、衣摆、武器与背景形。
- 允许角色偏置、切边、前景遮挡和图形框景；不默认正中完整展示。
- 复杂度集中在 1–2 个 focal pockets，邻接区域刻意降密度。
- 颜色先看 3–4 个大色块，再放唯一强调色；不要靠柔和渐变消除冲突。
- 光影必须塑造体积和材质，优先清晰局部阴影与接触阴影，不用全局 bloom 制造高级感。
- 人物的脸、皮肤、头发和配饰保留有限的手绘不规则：眼睛不必镜像，高光不必堆叠，头发以发量结构优先。
- 首饰、布带、链条、流苏等必须有可解释的 attachment point；能删掉的装饰优先删。
- 故事感可以来自一个动态动作、一个被打断的动作或一个明确的 before/after，不必强行加入复杂环境。

## 参考校准：高完成度插画的结构特征

参考 `references/visual-grammar.md`。重点不是模仿某位作者，而是吸收这些可迁移的结构策略：

1. **建筑框景**：巨大门、镜、窗、拱、画框、轨道等形成多重视觉平面，人物是几何结构中的一个元素。
2. **有机包围**：头发、花、布、枝、鸟群、水流等形成环绕或穿越人物的线性结构，并把密集区包进留白中。
3. **极端尺度**：让人物足够小，让海、天空、墙、路、建筑或空房间成为真正的视觉主体。
4. **环境叙事**：环境不是装饰，而是人物行为的前后证据；一个空椅、未收的物、错位倒影往往比十个魔法符号更有故事。
5. **大色块优先**：先让缩略图成立，再让局部细节成立。
6. **白也可以是高密度构图**：白底、白发、白裙、白建筑可以通过边缘、材质、阴影、透叠和几何切割形成层次，而不是依靠大量颜色。

## 自检

- [ ] 能用一句视觉句子说明画面命题吗？
- [ ] 能说出前 1 秒和后 1 秒吗？
- [ ] 有且只有一个主要视觉母题吗？
- [ ] 环境是否真的对人物做了某件事？
- [ ] 人物居中 / 看镜头 / 占满画面——如果是，理由是什么？
- [ ] 是否存在有意的尺度差？
- [ ] 是否有至少一处受控遮挡或空间切割（如果题材允许）？
- [ ] 光源有位置和衰减吗？画面里有敢于压暗或留白的区域吗？
- [ ] 背景是一层还是三层？多余层删了吗？
- [ ] 花瓣、粒子、光点、蝴蝶等是否被拿来填空？如果是，删除。
- [ ] 密集区 / 安静区 / 动线是否明确？
- [ ] 叙事残留是她造成的，还是至少与她的故事有关？
- [ ] 超现实元素是否只有一个核心怪点？
- [ ] 缩略图里能看出重的地方和视觉动线吗？
- [ ] 删除所有装饰后，画面命题仍然成立吗？
- [ ] 只开了一个氛围预设吗？
