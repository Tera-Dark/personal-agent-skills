# L2 Concept Poster Task Card
For album covers, vertical story posters, editorial designs and experimental fantasy concepts. Escalate L3 for unfamiliar canon, multi-scene storytelling or ambiguous medium.

Start with one visible thesis and dominant thumbnail shape. If the user has explicitly complained about empty composition, merely describing symbolic meaning, or inherited staging from a previous artwork, escalate to L3 director `references/visual-taste-evidence-protocol.md` before choosing the winning design; never copy the last scene's angels/crowd/lighting into an unrelated brief. Decide title safe area, foreground/background and negative space. Every character, graphic element and light mass must contribute to the same relationship; neither overdecorate nor default to plain standing portraits.
Creative intensity: cinematic for narrative staging, experimental for form/visual metaphor. Whichever suits user intent; not every poster needs surrealism.
Owner boundaries: director owns concept, illustration-direction owns concrete layout and physical lighting; small-artist module is optional guidance. Renderer must not redesign.

MOSS: album covers normally use Caption; if exact title position or multi-panel boxes are essential use checked native JSON Layout after geometry conversion.
