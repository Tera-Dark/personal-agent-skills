# L2 Cinematic Duo Task Card
For known two-person subjects with a defined interaction or two-panel storyboard. Escalate L3 on complex staging or uncertain identity.

Verify actual character sex/number, signatures and outfits BEFORE composing. Give each participant a different objective, time-offset reaction, distinct hands and weight-bearing touch points; only include gestures motivated by the scene. Select an observational viewpoint that changes the emotional reading, not automatic rain, sunset or bloom.
Creative intensity: daily for natural everyday interactions; cinematic for narrative shot decisions.
Owner boundaries: aesthetic director chooses relation; illustration-direction approves camera, action, foreground and lighting.
NAI5: shared count and scene in Base Prompt; each independent Character Prompt owns its own identity, clothes and actions. For delivery one block may contain human-readable character 1 / character 2 headings; headings are NOT actual model tags. Do not mix them with pipe syntax.
