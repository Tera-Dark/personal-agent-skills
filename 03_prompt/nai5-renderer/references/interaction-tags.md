# NAI5 Interaction Tags

## Multi Character Relations

Use relationship markers instead of mixing actions.

Common community patterns:

```text
source#action
target#action
mutual#action
```

Example:

```text
char1:
source#princess carry

char2:
target#princess carry
```

## Single Character Actions

Use direct action tags:

```text
holding sword
looking at viewer
standing
floating
```

Keep action information close to the character it belongs to.
