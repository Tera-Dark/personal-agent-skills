# Artist Eye Cross-Media Regression · 2026-10-16

## 目的与执行

人工对照测试；**不是已跑图的自动通过报告**。由 aesthetic-director-core 生成方向，illustration-direction/character-design-engine 决定空间与服设，renderer 再编译；evaluation-loop 按用户关注问题区分设计、执行和技术原因。

每题必须回答：命题、三向候选的**不同视觉机制**、两项淘汰理由、幸存方案的机位/版式、环境职责、缩略图大形、一处可见的非默认决定、删除项。默认不给用户展示内部候选，除非用户要求设计方案或验收过程。不会因为测试要求就自动生成图片。

## T1 · 极简白底，认得出是谁

Brief：「黑绿挑染、M形自然翘发、琥珀眼、墨绿马甲、红领结的 OC，笑颜头像；纯白背景」。

- PASS：身份锚点保留，头发尖角**是头发本身**不是猫耳；通过头肩轮廓、非标准眼眉、手指微动作形成个性；背景仍纯白。
- FAIL：添加猫耳、让长发变绿、给她加天台或花束来撑电影感。
- 激活 Lens：动画表演、平面负形；无需强求电影场景。

## T2 · 室内日常双人，行为让关系成立

Brief：「两位 OC 在室内修理一盏旧灯，不能出现浪漫摆拍；竖图七分身到半身」。

- PASS：两人看同一真实接触处但动作/反应不同步；手和器物有受力支点；光源可验证；画幅能看清关系。
- FAIL：两人同步甜笑看观众、左一右一、器物悬浮，或无原因出现樱花/飞纸。
- 激活 Lens：纪实摄影、动画表演、材料承重。

## T3 · 中式阈限恐怖，但不堆道具

Brief：「旧式招待所凌晨，阴郁瘦弱少女，安静的中式恐怖感，不要鬼脸」。

- PASS：唯一空间异常与少女下一步选择有直接关系；主要视觉事实在手机小图也能读出。
- FAIL：春联+纸钱+供台+灯笼+红雾+鬼影平均堆满。
- 激活 Lens：建筑空间、观看权限、灯光边界。

## T4 · 数摇唱片封面，不套公式

Brief：「日式数摇/实验专辑封面，忧郁少女，可抽象，1:1，留标题安全区」。

- PASS：三向候选里至少有纯图形/编辑候选，不自动选择天桥、铁轨、蓝天、电线杆；颜色与节奏的规则可被描述。
- FAIL：把「数摇」等价成少女+天桥+落日，再加无意义碎玻璃。
- 激活 Lens：编辑版式、视觉节奏、空间隐喻。

## T5 · IP 群像，人物不被概念吞没

Brief：「三位原 IP 角色的 2:3 垂直海报，场景与原剧情有关」。

- PASS：先核实正典与原版服设；各角色在画面有不同的动作责任，主轴与安全区明确，IP 辨识度没有丢。
- FAIL：为了创意擅自改发色、道具或衣装，所有人机械站桩，电影感仅来自烟雾。
- 激活 Lens：分镜、编辑主图形、叙事信息差。

## T6 · 反参考复制压力测试

Brief：「受 U3 螺旋楼梯图启发，画『和解』，但不能再出现楼梯、中心圆窗或俯视同心线」。

- PASS：保留「机位使人物关系变得可见」的抽象原则，改成如狭长地面投影/屏风透叠等另一种几何机制，且不仅仅换素材。
- FAIL：把螺旋楼梯换成同心花环，原几何结构原封照搬。
- 激活 Lens：反事实、原创距离、形式机制迁移。

## T7 · 极简电影静帧，允许不出现人脸

Brief：「一个人决定离开，画面只有可见手或背影，1:1；不要标题，不要胶片颗粒」。

- PASS：门/衣袖/阴影的一处状态改变能让人知道做了决定；空间与光有明确职责；不要求脸部特写。
- FAIL：用文字解释悲伤，或者强制画出对镜头微笑的大脸。
- 激活 Lens：摄影、视觉留白、环境残留。

## T8 · 反对「越怪越高级」

Brief：「白底淡雅女性向半身高定 OC；美型必须优先，用户不希望任何超现实内容」。

- PASS：服装结构、材料区别、动作、脸部魅力与留白有组织；明确省略怪点/叙事反转。
- FAIL：必须给她加异形肢体、漂浮面具、传送门，靠噱头获得所谓记忆点。
- 激活 Lens：服设构造、肖像、图形层次。

## 回归红线

- 用户没有说生图 → 只写设计/Prompt；不得调用图片生成。
- NAI5 默认省略外部固定画师串、年份、质量、负面；多角色用户要求 `主词 / character 1: / character 2:` 则一个文本块分节展示（标签用于阅读，官方输入应拆为 Base + Character fields，不把标签文字作为模型 tag）。
- 区分未验证新 tag 与可用自然语言描述，不杜撰 Danbooru canon。
- 通过文字测试 ≠ NAI5 出图已验证。
