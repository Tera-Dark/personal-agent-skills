# Artist Eye · 艺术性评审与反模板 A/B（2026-10-16）

> 归属：evaluation-loop **只诊断**。判定失败在哪一层，交回已有 owner；不得在这里重写 Prompt 或创作新方案。面向原型提案 / 已生成图两种不同证据级别。原有六维技术回归表仍保留。

## 0. 优先硬约束

首先检查用户明确指定的角色/IP/画幅/媒介/原版服饰及安全约束。若身份错、人设错或出现用户禁止的元素，无论美感如何都不能宣称 PASS。新颖度、美感、信息清晰是并列的设计质量维度，不允许用任一维压倒硬约束。

## 1. 六个「可追责而非伪科学」的美学问题

| 维度 | 可观察证据 | Fail 信号 | 路由 |
|---|---|---|---|
| 视觉命题 | 去掉标题，能指认哪两个具体东西发生关系 | 只能说「美丽忧伤女孩」 | aesthetic-director-core |
| 独立的主图形 | 96px 缩略图仍读得出大形/主方向/明度焦点 | 只是常规人物居中+素材装饰 | illustration-direction |
| 角色生命/因果 | 姿势由接触、目的或内心反应解释 | A 与 B 面面相觑、不知为何碰触 | illustration-direction / character-design-engine |
| 观看立场/信息差 | 有特定机位或有意平面化；裁切理由可复述 | 随便换平视，情绪不变 | illustration-direction |
| 色块/节奏 | 亮暗层次、疏密、色差服务主命题 | 每处都亮、每处都密、所有边缘同样锐利 | illustration-direction |
| 创作必要性 | 至少一项决定换人/删物/换机位后明显失效 | 把同张图换个颜色或花朵仍成立 | aesthetic-director-core |

采用 `FAIL / WEAK / PASS / N/A` 标记并给出**一条对应的可见证据**；不是虚构的 98/100 审美分。只给最早的失败层一个优先修复动作。静态形式主义作品的「人物动作」可以 N/A，但必须用图形或材料节奏证明主张。

## 2. 创意距离与引用伦理

- 同场景、同机位、同角色位置、同关键道具、同配色 → 疑似照搬：不是因为「加了原创人物」就合格。
- 只迁移关系逻辑（共同承担重量 / 观看权限限制 / 密度梯度等），同时改变至少**两项主结构**（例如主图形、人物关系、机位、作品媒介）→ 可评估的原创候选。
- 对 IP 同人可以保留正典身份与用户授权的原设，不能拿「提高新颖性」作 OOC 借口。
- 用户明确让重现构图/忠实反推时应忠实，别强行改造；按任务分类，不拿原创规则惩罚忠实复刻。

## 3. 最小 A/B 实验协议

1. 保存 Baseline 的主题、角色锚点、seed、模型、画幅、外部固定画师/质量词、采样等参数。
2. 先给出 `A`：原方案；`B`：**仅改变一个创作机制**（如观察立场），不同时换衣服、背景、配色。
3. 预先写出预测的视觉变化，例如「B 的主图形将让主角与出口之间的距离可读，A 不会」。
4. 出图后分别核对：身份锁定、主图形、动作因果、摄影几何、颜色实际呈现、模型是否遵从。
5. 主观反馈独立记录成功与失败维度，必要时可由用户打分；**不能在未出图时声称胜率、还原率或用户认可**。
6. 若 B 失败，定位是画面设计弱还是模型执行偏差，回退至最上游错误层；不能靠增加质量词补丁式解决。

## 4. 创作型任务验收等级

- `SPEC`：文字提案/设计方案可评审，尚无 NAI5 图。
- `IMAGE-PENDING`：已转换 Prompt，等待用户实际生成。
- `USER-IMAGE-REPORT`：用户描述了出图表现，但未能直接检验细节，保持证据来源标签。
- `IMAGE-REVIEWED`：已看到可对照的输出图，可评具体构图表现。
- `USER-APPROVED`：用户认可具体出图及具体维度，记录范围，才允许将喜好交给个人 Identity 反馈晋升机制。

没有自动、无限持续的学习；新会话只能用仓库里已保存的文字规范与明确的用户反馈记录。自动指标不凌驾于人类对艺术作品的评价。

## 5. 真实交付的一句话结果样式

`Artist Eye: SPEC · 命题 PASS（「阴影先于旅人抵达门」） · 主图形 PASS（门外亮楔） · 人物因果 WEAK（抬手未与物件接触） · 优先修正：illustration-direction 只改接触点，锁定身份与色块；未生成图。`

PROMPT ONLY 任务在内部记录，不把此诊断长单发给用户；只有用户要求评价、复盘、改进方案时展示。
