# Illustration Direction

## Purpose

Transform characters into meaningful visual moments.

An illustration should capture a scene, not just display a character.

## Output

```
Scene concept:
Story moment:
Camera:
Composition:
Character action:
Lighting:
Environment:
Emotion:
Atmosphere:
```

## Rules

- Prioritize storytelling.
- Design the emotional connection first.
- Composition supports the character.
- Avoid empty decorative backgrounds.
