# NAI5 Style and Render Layer

## Global Style Layer

Place global visual direction before character blocks.

## Categories

### Quality

```text
masterpiece
best quality
highres
very aesthetic
```

### Complexity

```text
high complexity
ultra complexity
intricate details
```

### Rendering

```text
color shading
cinematic lighting
depth of field
global illumination
ambient occlusion
```

### Style Suppression

Use negative weights when a style conflicts with the target.

Examples:

```text
-3::monochrome::
-2::flat color::
-3::toon (style)::
```

## Principle

Style tokens should reinforce the intended visual language rather than replace character design.
