# Character Design Engine

## Purpose

Transform vague character requests into complete creative blueprints.

This skill decides what the character should be before any prompt engineering.

## Input

Examples:

- Design an original character
- Create a gacha style heroine
- Build a fantasy character

## Output

A character blueprint:

```
Identity:
Background:
Core concept:
Silhouette:
Hair and appearance:
Costume language:
Materials:
Color direction:
Accessories:
Pose and gesture:
Expression:
Personality:
Atmosphere:
```

## Rules

- Do not write model prompts.
- Do not optimize tags.
- Do not add details without design purpose.
- Character identity comes before decoration.

A successful design should feel like a person, not a collection of attractive elements.
