# Costume Design Principles

## Core Rule

Costume is character storytelling.

Every major element should communicate:

- identity
- personality
- background
- world

## Preferred

- layered clothing
- elegant silhouette
- high-fashion influence
- meaningful ornaments
- controlled complexity

## Avoid

- random accessories
- meaningless straps
- decoration overload
- complexity without hierarchy

Complexity should be organized, not chaotic.
